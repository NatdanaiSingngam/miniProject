# 🍱 Pinto (ปิ่นโต)
แอปจดสูตรอาหารออนไลน์ เชื่อมต่อข้อมูลได้ทุกที่ด้วยระบบ Cloud Sync

## ✨ ฟีเจอร์หลัก
- 📝 **จดสูตร:** บันทึกชื่อเมนูและวิธีทำ
- ☁️ **Cloud Sync:** เชื่อมต่อห้องด้วย Room ID & PIN
- 📱 **PWA:** ติดตั้งลงมือถือได้เหมือนแอปจริง
- 🔍 **Search:** ค้นหาเมนูได้ทันที

## 🛠️ เทคโนโลยีที่ใช้
- HTML, CSS, JavaScript (Vanilla)
- Tailwind CSS
- Firebase Realtime Database
